# A programmer's guide to Sparse Autoencoders

Motivation
We can use SAEs to pull out what an LLM knows, then we can use that knowledge to guide its behavior.

This article will give you the conceptual intuition and provide a hands on way to work with them yourself.
We will use Gemma 2 2B to demonstrate, a model that can run efficiently enough on a CPU to experiment with. 
We'll show you the code for each step.

Let's get SAE in your toolbox.
New SAEs are being researched and trained, they will get better and more interpretable, and available for more open models.

[[CODE FOR INFERENCE (simple using python transformers)]]
```python
tokenizer = AutoTokenizer.from_pretrained("google/gemma-2-2b")
model = AutoModelForCausalLM.from_pretrained("google/gemma-2-2b")

input_text = "Hello, my name is"
inputs = tokenizer(input_text, return_tensors="pt", add_special_tokens=True)
outputs = model.generate(**inputs, max_new_tokens=10)
```

# Enter the SAE

Instead of getting back all of the hidden states, we can use a forward hook to get the embeddings for a specific layer.
This idea of reaching into the model at a particular layer and looking at it's activations will come back when its time to change the model's behavior.
